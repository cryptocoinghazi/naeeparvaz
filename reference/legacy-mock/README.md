# Naee Parvaz Professional Website Mock

Open `index.html` in a browser.

## Pages
- `index.html` — Home / institutional introduction
- `about.html` — About the publication
- `vision.html` — Vision, mission, objectives and editorial principles
- `contact.html` — Chief Editor and official contact channels

## Assets
- `assets/naee-parvaz-masthead.png` — supplied Naee Parvaz logo/masthead artwork
- `assets/editor-contact-banner.png` — supplied editor/contact/social banner
- `styles.css` — responsive newsroom/editorial visual system
- `script.js` — small mobile navigation interaction

## Visual direction
The design intentionally follows the supplied Naee Parvaz identity: deep blue, red, yellow and restrained Indian tricolour accents. Rounded generic SaaS cards were avoided in favour of editorial rules, newspaper-style typography and structured newsroom information.
